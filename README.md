# Python Fundamentals – Assignment 3

## 📌 About the Project

This repository contains my Python Fundamentals Assignment 3, completed as part of my Python learning journey. It demonstrates the practical use of loops, control statements, and functions through simple Python programs.

## 🎯 Objectives

- Understand and implement `while` and `for` loops.
- Practice control statements such as `break`, `continue`, and `else`.
- Learn to use Python's `range()` function.
- Create reusable functions to perform calculations.
- Improve logical thinking and problem-solving skills using Python.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook
- **File Format:** `.ipynb`

## 📂 Programs Included

### 1. Number Guessing Game
A simple guessing game that demonstrates the use of a `while` loop and control statements such as `break`, `continue`, and `else`.

### 2. Multiplication Table
Generates a multiplication table using a `for` loop and Python's `range()` function.

### 3. BMI Calculator
Calculates Body Mass Index (BMI) using a user-defined Python function.
